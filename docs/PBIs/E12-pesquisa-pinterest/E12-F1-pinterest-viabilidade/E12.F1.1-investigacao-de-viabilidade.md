## Contexto

O mural de referências aceita imagens da galeria do dispositivo e não usa a API do Pinterest. Importar referências do Pinterest só deve ser planejado se a API oficial e os termos permitirem o fluxo desejado.

## Descrição

- Relatório de viabilidade, com fontes oficiais citadas (com data de consulta), sobre:
  - existência e disponibilidade da API oficial;
  - possibilidade de buscar e importar Pins;
  - permissões e escopos necessários;
  - restrições para aplicativos novos;
  - custos e limites de uso;
  - requisitos de aprovação;
  - se imagens e informações dos Pins podem ser obtidas;
  - regras de armazenamento, exibição, atribuição e uso por IA (o mural salva a imagem e o Gemma a analisa);
  - alternativas oficiais caso o fluxo desejado não seja permitido.
- Não se presume que a API permita importar qualquer imagem.

Para aqui: não implementa nada e não propõe formas de contornar restrições do Pinterest.

## Escopo

**Dentro:** leitura da documentação e dos termos oficiais, registro dos achados, lista de perguntas sem resposta confiável.

**Fora de escopo:** código; scraping ou qualquer acesso não autorizado; criar app de desenvolvedor sem decisão do usuário.

## Como será feito

- Consultar a documentação de desenvolvedores do Pinterest (níveis de acesso, escopos, limites) e as diretrizes para desenvolvedores.
- Pontos já levantados numa consulta preliminar, a **confirmar** no relatório: níveis Trial e Standard; Standard exige vídeo da demonstração do fluxo OAuth; apps registrados a partir de 14/09/2026 podem receber 403 ao pedir pins de contas não empresariais; as diretrizes restringem armazenar dados da API e treinar IA com o conteúdo.
- Cada afirmação do relatório cita a URL e a data; o que não for confirmado fica marcado como tal.
- Arquivo: `docs/pesquisa/pinterest-viabilidade.md`.

## Critérios de aceite

- Dado o relatório, então cada item da lista da Descrição tem resposta com fonte oficial e data, ou está marcado como "não confirmado".
- Dado o conflito entre as regras de armazenamento/IA e o mural, então ele é analisado de forma explícita.
- Dado o relatório, então não contém nenhuma proposta de scraping nem de contornar restrições.
- Dado o relatório, então termina com recomendação fundamentada para a E12.F1.2.
